# Milestone Archive: v1.0 Requirements

**Shipped:** 2026-10-04  
**Coverage:** 39 / 39 Requirements Satisfied (100%)

---

## 1. Authentication & Authorization
- [x] **AUTH-01**: User can register an account with name, email, password, and location (Validated in Phase 2)
- [x] **AUTH-02**: User receives an initial platform grant of 5 time credits upon registration (Validated in Phase 2)
- [x] **AUTH-03**: User can log in with email and password and receive a JWT authentication token (Validated in Phase 2)
- [x] **AUTH-04**: User session persists across page reloads and browser refresh (Validated in Phase 2)
- [x] **AUTH-05**: User can log out and invalidate their active session (Validated in Phase 2)

## 2. User Profiles & Skill Catalog
- [x] **PROF-01**: User can view and edit their profile (bio, location, contact, avatar URL) (Validated in Phase 3)
- [x] **PROF-02**: System provides a categorized catalog of skills (Technology, Languages, Academics, Trades, Arts, Wellness) (Validated in Phase 3)
- [x] **PROF-03**: User can add and remove skills they offer, specifying proficiency / experience level (Validated in Phase 3)
- [x] **PROF-04**: User can add and remove skills they want to learn or receive (Validated in Phase 3)
- [x] **PROF-05**: User can view public profile of any member showing offered/wanted skills, bio, and reviews (Validated in Phase 3)

## 3. Skill Discovery & Search
- [x] **DISC-01**: User can search available skills by keyword and title (Validated in Phase 4)
- [x] **DISC-02**: User can filter providers by skill category, location, and minimum rating (Validated in Phase 4)
- [x] **DISC-03**: User can browse member cards on the Explore Skills page with clear skill tags and badges (Validated in Phase 4)

## 4. Matching & Recommendations
- [x] **MATCH-01**: System calculates compatibility scores between complementary member needs (`0.4*Skill + 0.2*Location + 0.15*Availability + 0.15*Rating + 0.1*Experience`) (Validated in Phase 5)
- [x] **MATCH-02**: User can view personalized recommendations on their dashboard (Validated in Phase 5)
- [x] **MATCH-03**: System supports AI-assisted semantic matching for skill synonyms and complementary pairings (Validated in Phase 5)

## 5. Exchange Request Lifecycle
- [x] **EXCH-01**: User can create an exchange request to a provider specifying skill, proposed duration in hours, and details (Validated in Phase 6)
- [x] **EXCH-02**: System prevents self-requests and enforces sufficient credit balance before sending (Validated in Phase 6)
- [x] **EXCH-03**: Provider can accept or reject an incoming exchange request (Validated in Phase 6)
- [x] **EXCH-04**: Requester can cancel a pending exchange request (Validated in Phase 6)
- [x] **EXCH-05**: User can view and filter incoming and outgoing exchange requests on the Exchanges page (Validated in Phase 6)

## 6. Booking & Scheduling
- [x] **BOOK-01**: Requester and provider can schedule a date, start time, and end time for accepted exchanges (Validated in Phase 7)
- [x] **BOOK-02**: System tracks upcoming bookings and displays them on user dashboard and exchange management (Validated in Phase 7)
- [x] **BOOK-03**: Users can reschedule or cancel an existing booking prior to service commencement (Validated in Phase 7)

## 7. Service Completion & Dual Confirmation
- [x] **CMPL-01**: Requester and provider can both independently confirm service completion (Validated in Phase 8)
- [x] **CMPL-02**: System transitions exchange state to `COMPLETED` when dual confirmation is received (Validated in Phase 8)
- [x] **CMPL-03**: Participants can report an exchange as disputed if service was not delivered (Validated in Phase 8)

## 8. Time-Credit Wallet & Transaction Ledger
- [x] **WALL-01**: System maintains a secure wallet for each member with current credit balance (Validated in Phase 2 & 9)
- [x] **WALL-02**: System automatically executes an atomic transaction transferring credits (1 hour = 1 credit) from receiver to provider upon completion (Validated in Phase 9)
- [x] **WALL-03**: System records every credit movement in an immutable audit ledger (`credit_transactions`) (Validated in Phase 9)
- [x] **WALL-04**: System prevents duplicate settlement and strictly enforces non-negative credit balances (Validated in Phase 9)
- [x] **WALL-05**: User can view their current balance, total credits earned, total credits spent, and complete transaction history (Validated in Phase 9)

## 9. Trust & Reputation
- [x] **REV-01**: User can submit a star rating (1–5) and written feedback for a completed exchange (Validated in Phase 10)
- [x] **REV-02**: System restricts reviews so only participants of a completed exchange can submit (max 1 review per participant per exchange) (Validated in Phase 10)
- [x] **REV-03**: System computes and updates aggregate member ratings displayed on profile cards and pages (Validated in Phase 10)

## 10. In-App Notifications
- [x] **NOTF-01**: System generates in-app notifications for request events (received, accepted, scheduled, completed, credits transferred, reviews) (Validated in Phase 11)
- [x] **NOTF-02**: User can view notifications in navbar dropdown and mark them as read (Validated in Phase 11)

## 11. Dashboard & Page Experience
- [x] **DASH-01**: Dashboard aggregates credit balance, active requests, upcoming bookings, and recommendations (Validated in Phase 11)
- [x] **DASH-02**: Complete responsive frontend across 9 main pages with clear empty and loading states (Validated in Phase 11)
