<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser Form -> Axios Client | User input validated before transmission; passwords kept in component state only |
| Axios Interceptor -> localStorage | Bearer token retrieved from localStorage and attached to headers |
| ProtectedRoute -> Browser Router | Unauthenticated users denied access to private dashboard and exchange views |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-05 | Information Disclosure | localStorage token storage | medium | mitigate | Token lifetime limited to 24 hours (D-06); token cleared on logout (AUTH-05) and on any 401 response (D-08) |
| T-02-06 | Elevation of Privilege | ProtectedRoute bypass | high | mitigate | Client ProtectedRoute redirects to /login; backend Spring Security independently enforces JWT validation on all /api/v1/* data requests |
| T-02-07 | Tampering | Welcome Modal credit display | low | mitigate | Modal displays the balance returned by the backend response, not client-invented credit values (D-01, D-02) |
| T-02-SC | Tampering | Frontend npm packages | high | mitigate | Pin axios, lucide-react, react-router-dom versions in package.json |
</threat_model>
