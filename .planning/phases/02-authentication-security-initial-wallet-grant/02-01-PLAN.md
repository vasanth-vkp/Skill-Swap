<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client -> AuthController | Untrusted user registration and login credentials cross HTTP boundary |
| JwtAuthenticationFilter -> SecurityContext | Untrusted Bearer token header validated before granting principal access |
| AuthService -> Database | Passwords must never be stored in plain text; balance must be set server-side |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Tampering | Wallet balance initialization | critical | mitigate | Balance grant of 5 credits is hardcoded server-side in @Transactional service method; client cannot specify initial balance (WALL-01) |
| T-02-02 | Spoofing | JWT token generation & validation | high | mitigate | Signed with HMAC-SHA256 secret key; signature verified on every request; 24-hour expiration enforced (AUTH-03, D-06) |
| T-02-03 | Information Disclosure | Password storage | critical | mitigate | Passwords hashed with BCrypt (strength 12) before persisting; never returned in DTOs or logs (D-07) |
| T-02-04 | Denial of Service | Registration email collision | medium | mitigate | Email uniqueness enforced via database unique constraint and pre-check throwing 409 Conflict |
| T-02-SC | Tampering | JJWT library dependency | high | mitigate | Strict dependency pin on io.jsonwebtoken:jjwt-api:0.12.6 from Maven Central |
</threat_model>
