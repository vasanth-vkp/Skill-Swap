# Plan 11-02: Frontend Notification Bell Dropdown, Dashboard Polish & End-to-End Verification

## Objective
Build the client-side notification experience and perform complete end-to-end polish:
- Create `notificationService.js` client interacting with `/api/v1/notifications`.
- Implement `NotificationBell.jsx` component in `Navbar.jsx`:
  - Bell icon with unread badge counter.
  - Dropdown panel showing latest notifications with icons, relative timestamps, and unread highlight.
  - Quick action: "Mark all as read".
  - Notification click: marks item as read and navigates to target route (`/exchanges`, `/wallet`, `/profile`).
- Polish `Dashboard.jsx`:
  - Show active unread notifications alert banner or summary card if user has unread notifications.
  - Show active exchange quick-stats (pending incoming requests counter, scheduled sessions).
- Perform end-to-end verification across all 9 SPA pages:
  - Landing (`/`), Login (`/login`), Register (`/register`), Onboarding (`/onboarding`), Explore (`/explore`), Member Profile (`/members/:id`), My Profile (`/profile`), Exchanges (`/exchanges`), Wallet (`/wallet`), Dashboard (`/dashboard`).
- Write tests for `NotificationBell.test.jsx`, update `Navbar.test.jsx` / `Dashboard.test.jsx`.
- Run full backend + frontend test suite and generate production bundle with zero errors.

## Execution Context
- React 19, Vite, Tailwind CSS, Lucide Icons, Vitest, React Testing Library.
- Existing pages: `Dashboard.jsx`, `Exchanges.jsx`, `MemberProfile.jsx`, `Wallet.jsx`, `ExploreSkills.jsx`.
