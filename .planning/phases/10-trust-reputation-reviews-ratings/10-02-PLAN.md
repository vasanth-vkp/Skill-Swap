# Plan 10-02: Frontend Review Submission Modal, Star Rating Selector, Profile Reviews & Exchange Card Integration

## Objective
Build the client-side review and reputation interface:
- Create `reviewService.js` client consuming `/api/v1/reviews`.
- Implement `SubmitReviewModal.jsx` featuring an interactive 1–5 star selector with hover feedback, descriptive rating labels, and textarea comment field.
- Implement `ProfileReviews.jsx` displaying member reputation metrics, star rating breakdown, and verified review cards.
- Integrate "Leave Review" CTA into `ExchangeCard.jsx` for completed exchanges.
- Embed `ProfileReviews.jsx` into `MemberProfile.jsx`.
- Write unit tests in `SubmitReviewModal.test.jsx` and `ProfileReviews.test.jsx`.
- Execute full regression verification across backend and frontend tiers with clean Vite production build.

## Execution Context
- React 19, Vite, Tailwind CSS, Lucide Icons
- Vitest, React Testing Library, jsdom
- Existing files: `ExchangeCard.jsx`, `MemberProfile.jsx`, `frontend/src/services/api.js`

       - `getReviewsForMember: async (memberId) => (await api.get(`/reviews/member/${memberId}`)).data`

       - Submit button disabled when rating is 0 or while submitting.
       - Error banner when submission fails.
       - On success: invoke `onSuccess(review)` and close modal.
    3. Create `frontend/src/components/review/__tests__/SubmitReviewModal.test.jsx`:
