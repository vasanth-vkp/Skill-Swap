# Plan 07-02: Frontend Booking Modal, Dashboard Upcoming Widget, Exchange Card Integration & Tests

## Objective
Implement the frontend scheduling experience allowing participants of accepted skill exchanges to schedule sessions via a modal dialog, view upcoming sessions on the dashboard with relative time badges, and reschedule or cancel bookings seamlessly.

## Execution Context
- React 19, Vite, Tailwind CSS, Lucide Icons, Vitest + React Testing Library
- Existing components: `Dashboard.jsx`, `ExchangeCard.jsx`, `Exchanges.jsx`
- Backend API endpoints established in Plan 07-01 (`/api/v1/bookings` & `/api/v1/exchanges/{id}/book`)

  <action>
    1. Create frontend/src/services/bookingService.js:
       - `scheduleBooking(exchangeId, { startTime })`: POST `/api/v1/exchanges/${exchangeId}/book`
       - `rescheduleBooking(bookingId, { startTime })`: PUT `/api/v1/bookings/${bookingId}/reschedule`
       - `cancelBooking(bookingId)`: DELETE `/api/v1/bookings/${bookingId}`
       - `getUpcomingBookings()`: GET `/api/v1/bookings/upcoming`
       - `getBookingForExchange(exchangeId)`: GET `/api/v1/exchanges/${exchangeId}/booking`
    2. Create frontend/src/components/booking/ScheduleBookingModal.jsx:
       - Props: `isOpen`, `onClose`, `exchange`, `existingBooking`, `onSuccess`.
       - Mode: Scheduling new session or Rescheduling existing session.
       - Duration display: Highlights exchange duration (e.g., "1.5 Hours / 1.5 Credits") with Clock icon.
       - HTML5 datetime-local input: `min` set to 15 minutes from now.
       - Calculated End Time Preview: Automatically updates to show formatted completion time based on selected start time + duration.
       - Error banner for conflict (409) or validation errors.
       - Submit button with spinner loading state.
    3. Write frontend/src/components/booking/__tests__/ScheduleBookingModal.test.jsx:
       - Tests rendering modal in Schedule mode with skill name and duration.
       - Tests calculating and displaying estimated end time upon start time selection.
       - Tests submitting scheduling request dispatches `bookingService.scheduleBooking`.
       - Tests rendering modal in Reschedule mode pre-populating existing booking time.
       - Tests error banner when API returns calendar conflict error (409).
  </action>

  </verify>
