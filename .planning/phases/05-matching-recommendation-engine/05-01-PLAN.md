    Create SemanticSkillMatcher.java:
      - Embedded synonym clusters (e.g. "Python" ↔ "Python Programming", "Math" ↔ "Calculus & Algebra", "Coding" ↔ "Web Development", "Design" ↔ "Graphic Design").
      - Cross-skill complementary pairings (Web Dev ↔ UI/UX, Python ↔ Data Analysis, Spanish ↔ English, Photo ↔ Video Editing).
      - matchSkills(String wantedSkill, String wantedCategory, String offeredSkill, String offeredCategory) -> double (1.0 for exact, 0.85 for synonym/complementary, 0.70 for same category, 0.0 for unrelated).
    Create CompatibilityCalculator.java:
      - computeCompatibility(requester, provider, matchedOfferedSkill, matchedWantedSkill, isMutualMatch) -> CalculationResult:
        - Score = 0.40*SkillScore + 0.20*LocationScore + 0.15*AvailabilityScore + 0.15*RatingScore + 0.10*ExperienceScore
        - LocationScore: 1.0 (same city), 0.9 (either Remote), 0.2 (different).
        - RatingScore: provider.averageRating / 5.0.
        - ExperienceScore: ADVANCED=1.0, INTERMEDIATE=0.75, BEGINNER=0.5.
        - If isMutualMatch: +0.10 bonus (capped at 1.0).
        - Converts to integer percentage (Math.round(score * 100)).
        - Collects matchReasons list (e.g. "Matches wanted skill: Python", "Mutual exchange partner", "Both in Seattle", "High rating (4.9)").
    Write SemanticSkillMatcherTest.java:
      - Tests exact match returns 1.0.
      - Tests synonyms (Math ↔ Calculus) return 0.85.
      - Tests complementary pairs (Web Dev ↔ UI/UX) return 0.85.
      - Tests unrelated skills return 0.0.
      - Tests CompatibilityCalculator formula weights and reason generation.
  </action>

      - Omits email, passwordHash, role, and wallet balance.
    Create RecommendationService.java:
      - getRecommendationsForUser(Long userId):
        - Loads user's offered and wanted skills.
        - Fetches candidate providers (all users except current user).
        - For each candidate:
          - Evaluates best matching skill candidate offers against user's wanted skills using SemanticSkillMatcher.
          - Checks if candidate wants any skill that current user offers -> determines isMutualMatch.
          - If user has no wanted skills yet, gracefully pairs with top-rated providers in popular categories.
          - Invokes CompatibilityCalculator to compute compatibility score and match reasons.
        - Filters out scores < 40%.
        - Sorts by isMutualMatch DESC, compatibilityPercentage DESC, providerRating DESC.
        - Limits to top 6 items.
    Create RecommendationController.java:
      - @RestController @RequestMapping("/api/v1/recommendations")
      - GET /api/v1/recommendations/me:
        - Resolves authenticated user ID from SecurityContext.
        - Returns ResponseEntity<List<RecommendationDto>>.
