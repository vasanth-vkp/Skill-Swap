<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client -> ProfileController | Authenticated user updating bio, location, avatar, and skills |
| Client -> Public Member Endpoint | Unauthenticated or authenticated users viewing other members' public profiles |
| UserSkillService -> Database | Skill deletion and creation must enforce user ownership |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering | Skill Catalog pollution | medium | mitigate | Standard categories enforced; custom skill creation sanitized and trimmed |
| T-03-02 | Elevation of Privilege | UserSkill IDOR Deletion | high | mitigate | UserSkillService deletes strictly by ID AND userId; cannot delete another user's skill |
| T-03-03 | Information Disclosure | Public Member Profile | high | mitigate | PublicMemberResponse explicitly excludes email, password hash, wallet balance, and private tokens |
| T-03-04 | Tampering | Skill Duplication | low | mitigate | uq_user_skill_type uniqueness constraint and exists check prevent duplicate skills per type |
</threat_model>
