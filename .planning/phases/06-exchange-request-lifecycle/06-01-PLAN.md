<task type="auto">
  <name>Task 2: Build ExchangeService with State Machine and Unit Tests</name>
  <files>
    backend/src/main/java/com/skillswap/platform/exchange/service/ExchangeService.java,
    backend/src/test/java/com/skillswap/platform/exchange/ExchangeServiceTest.java
  </files>
  <action>
    Create ExchangeService:
      - createExchangeRequest(Long requesterId, CreateExchangeRequest req):
        - Validate requesterId != req.providerId (reject self-requests with IllegalArgumentException).
        - Verify provider exists and offers skill (via userSkillRepository.existsByUserIdAndSkillIdAndType(providerId, skillId, "OFFERED")).
        - Check requester wallet balance >= duration (via walletRepository.findByUserId). Throw InsufficientBalanceException / IllegalArgumentException if low.
        - Save ExchangeRequest in PENDING status and return ExchangeDto.
      - getIncomingExchanges(Long providerId, ExchangeStatus status)
      - getOutgoingExchanges(Long requesterId, ExchangeStatus status)
      - getExchangeById(Long exchangeId, Long currentUserId): verify caller is requester or provider, else throw AccessDeniedException.
      - acceptExchange(Long exchangeId, Long currentUserId):
        - Verify exchange is in PENDING status.
        - Verify currentUserId == exchange.provider.id (only provider can accept).
        - Transition status to ACCEPTED.
      - rejectExchange(Long exchangeId, Long currentUserId):
        - Verify exchange is in PENDING status.
        - Verify currentUserId == exchange.provider.id (only provider can reject).
        - Transition status to REJECTED.
      - cancelExchange(Long exchangeId, Long currentUserId):
        - Verify exchange is in PENDING status.
        - Verify currentUserId == exchange.requester.id (only requester can cancel).
        - Transition status to CANCELLED.
    Write ExchangeServiceTest:
      - Test createExchangeRequest success.
      - Test self-request rejected.
      - Test insufficient wallet balance rejected.
      - Test provider does not offer skill rejected.
      - Test accept, reject, cancel status transitions and authorization violations.
  </action>
  <verify>
    <automated>mvn -f backend/pom.xml test -Dtest=ExchangeServiceTest</automated>
  </verify>
  <done>ExchangeService passes all business logic and security unit tests.</done>
</task>
